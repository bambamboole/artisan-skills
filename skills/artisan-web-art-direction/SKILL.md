# Direct Website Reference Images

Infer audience, conversion goal, and site type. Commit to one visual world: palette, typography character, material, image treatment, and a decisive hero. For a multi-section site, generate one horizontal reference image per section; keep the system consistent while varying composition, density, backgrounds, and CTA treatment. Give each section a clear job: hook, proof, explanation, or action. Use imagery structurally, not as filler; maintain hierarchy, generous rhythm, and implementation clarity. Avoid default text-left/image-right heroes, repeated card rows, fake dashboard/KPI clutter, generic AI gradients, and empty decoration. Prefer a concise concept over a pile of effects.
