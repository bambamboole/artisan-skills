# Build Kotlin Backends

Inspect the toolchain, build conventions, and nearby code first. Keep Ktor routes thin, validate boundaries, return explicit HTTP failures, and put reusable work in focused services. Model boundary data with `@Serializable` data classes and sealed types. For Java conversion, preserve behavior first; audit nullability, mutability, collections, generics, annotations, and JVM interop before idiomatic cleanup. For JPA, use regular entity classes, stable ID equality, explicit constraints, and targeted fetch plans. Add or update a focused Kotlin/Ktor test, then run the Gradle wrapper's narrowest relevant check.
