# Shape Work

Inspect the repository and applicable instructions before proposing work. Resolve facts from the code; ask only for
decisions that materially change scope or behavior. State the goal, constraints, and acceptance checks. Offer
alternatives only when their trade-off is real. Finish with the smallest decision-complete plan: behavior, interface
changes, failure handling, and verification. Do not create ceremonies, documents, or abstractions that the
task does not need.
